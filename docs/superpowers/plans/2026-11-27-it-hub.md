# IT Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build IT Hub, a front-end-only, clickable demo of a connected IT system (Help Center, Service Desk, Asset Inventory, four approval workflows, Dashboard) with fake data, deployable to Netlify.

**Architecture:** All business rules live in pure, tested functions in `src/domain/` that take a `DemoState` and return a new one (or an error). A single Zustand store wraps those functions, persists state to `localStorage`, and tracks the current person (role switcher). React pages read the store and call its actions; they hold no business logic.

**Tech Stack:** React 18, TypeScript, Vite, Tailwind CSS v4, shadcn/ui (Radix), Recharts, Lucide icons, React Router v6 (`BrowserRouter`), Zustand (`persist`), Vitest + Testing Library + jsdom.

**Spec:** `docs/superpowers/specs/2026-11-27-it-hub-design.md`

## Global Constraints

- App title "IT Hub". Company name and email domain come only from `src/config.ts`: `COMPANY_NAME = "Demo Company Sdn Bhd"`, `EMAIL_DOMAIN = "demo.example"`.
- No real Cypark text, logo, screenshot, staff name, IP or internal data anywhere. Cypark is named only on the About page, as Haikal's employer.
- Tokens (light): primary `#6366F1`, primary-strong `#4F46E5` (buttons, coloured text), secondary `#818CF8`, accent `#059669`, accent-strong `#047857` (buttons, text), background `#F5F3FF`, card `#FFFFFF`, foreground `#312E81`, muted `#EBEFF9`, muted-foreground `#475569`, border `#E0E7FF`, destructive `#DC2626`. Dark tokens keep ≥ 4.5:1 text contrast.
- Fonts: Fira Sans (UI), Fira Code (tags, IDs, serials). Card radius 10px, bento tile radius 16px, transitions 200–300ms, visible focus rings, honour `prefers-reduced-motion`.
- Icons: Lucide SVG only, no emoji.
- Light theme by default, follows system setting, manual toggle persisted.
- Bento layout on `/` and `/dashboard`; Soft UI cards everywhere else.
- Responsive at 375 / 768 / 1024 / 1440; sidebar becomes a drawer below 768px; no horizontal page scroll.
- Seed dates are relative to the `today` passed to `buildSeed`.
- `localStorage` key `it-hub:state`, schema `version: 1`.
- Netlify: build `npm run build`, publish `dist`, `public/_redirects` = `/* /index.html 200`.

## Review Focus

1. **Stored data is corrupt, from an old version, or `localStorage` throws (private window):** the app reseeds silently or runs in memory; it never shows a blank screen. Test in Task 6.
2. **Equipment/onboarding fulfilment with no in-stock laptop:** IT can mark "Awaiting stock"; the request stays open; picking an asset that is not In stock is refused. Test in Task 5.
3. **Serial number typed with different case or spaces:** compare trimmed and case-insensitive; a real mismatch returns an error and changes nothing. Test in Task 5.
4. **Requester has no line manager (a department manager or Head of IT submits):** the manager step is auto-completed with comment "Auto-approved: no line manager" and the request moves on. Test in Task 5.
5. **Stale action after a role switch (the current person is not the step's actor, or the request is already decided):** the domain function returns `{ ok: false }` and state is unchanged; the UI shows the error as a toast. Test in Task 5.

  - `cancelRequest(state, requestId, actorId, now): Result` — requester only, while Pending/Awaiting stock; ticket "Closed".
  - Completing any request: status "Completed", final step "done", ticket "Resolved" with comment `"Completed via <workflow title>"`, notify requester.
